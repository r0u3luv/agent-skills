# Authoring Guide

## Principles

- Keep `SKILL.md` short.
- Put detailed material in `references/`.
- Put deterministic or fragile procedures in `scripts/`.
- Keep examples realistic but minimal.
- Prefer one skill per repeatable workflow.

## Skill Shape

```text
skill-name/
  SKILL.md
  references/
  scripts/
  assets/
```

Only `SKILL.md` is required.

## Review Before Sharing

- Is the trigger description specific enough?
- Is the workflow useful without being overly rigid?
- Are large details outside `SKILL.md`?
- Is there at least one fixture or example task?
